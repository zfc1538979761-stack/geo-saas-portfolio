# T07 验收清单

- Provider：统一接口、Mock、Ark Chat Completions、TLS、401/403/429/5xx/超时分类、严格文章 JSON、费用配置。
- 任务：快速入队、数据库事实、签名信封、Redis 调度、独立 Worker、取消、失败重试、有限退避。
- 一致性：请求幂等、投递幂等、每次尝试唯一调用、失败不覆盖、成功新版本、人工重试保留尝试历史。
- 追溯：企业/关键词/问题/提示词精确版本/文本素材快照、AI 调用、Token、耗时、请求 ID、文章版本来源。
- 安全：A/B 租户隔离、文件素材拒绝、联系人排除、Mock 生产禁用、密钥/原始响应/完整上下文不出响应和日志。
- 数据库：T07 向前迁移、最新回滚、重新迁移，T01—T06 表保留。
- 闭环：HTTP 快速返回、Redis 投递、单独 Worker 消费、Mock 闭环与显式真实豆包闭环。
