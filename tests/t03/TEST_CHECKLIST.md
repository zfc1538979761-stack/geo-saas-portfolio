# T03 测试与验收清单

更新时间：2026-07-30

## 可信上下文与绕过

1. 企业上下文只由有效企业 Token 解析出的用户和企业身份建立。
2. URL、Query、Body、Header 中的 `company_id` 不参与上下文解析。
3. 未登录、过期、禁用用户、禁用企业不能建立上下文。
4. 普通企业角色不能申请或获得租户绕过。
5. 内部管理员必须具有独立身份、`tenant.scope.bypass` 专用权限和非空原因。
6. 合法绕过授权必须写入脱敏审计；当前不提供管理员 HTTP 入口。
7. 上下文不使用全局静态状态；请求/任务必须显式传递且结束后不可串用。

## A/B 企业数据作用域

8. A、B 企业分别只能列出自己的数据。
9. A 猜测 B 的 ID 时，读取、修改、删除均安全失败。
10. 跨企业与不存在资源返回相同结果，不泄露资源是否存在。
11. 新增时忽略调用方的 `company_id` 并自动绑定 A。
12. 批量操作含 B ID 时整体失败，A 数据也不发生部分更新或删除。
13. 列表、搜索、分页、计数和聚合只使用当前租户。
14. 关联查询、子查询同时约束主表和关联表租户。
15. 越权尝试写入结构化、脱敏的安全审计记录。
16. 未注册的企业资源和未接入统一契约的模型被守卫拒绝。

## 非业务底层契约

17. 缓存 Key 使用 `tenant:{company_id}:...` 命名空间。
18. 文件 Key 使用 `tenants/{company_id}/...` 命名空间并拒绝路径穿越。
19. 导出 Key 和异步任务标识包含租户命名空间。
20. 异步任务上下文必须验证服务端 HMAC 信封，篡改 `company_id` 后拒绝。
21. CLI、队列和定时任务缺少可信信封或上下文时拒绝访问。
22. 租户数据网关的读取、写入、删除、批量、关联、聚合和子查询共用同一作用域。

## 迁移与回归

23. T03 创建 `audit_logs` 及三组必要组合索引。
24. `user.company_id` 保留兼容旧会员的 NULL，但企业上下文拒绝 NULL；增加到 `companies.id` 的限制删除外键。
25. 企业范围内唯一键和高频索引规范包含 `company_id`。
26. 空命名空间执行 T01、T02、T03 全量迁移成功。
27. T03 最新批次回滚只撤销 T03 结构。
28. T03 回滚后重新迁移成功。
29. 正式 `fa_` 迁移、回滚、重迁移不破坏 T01/T02 数据。
30. T01、T02 全部自动测试继续通过。
31. PHP 语法、Git 空白和明文密钥扫描通过。
