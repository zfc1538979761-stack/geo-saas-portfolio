# T08 验收清单

- 统一供应商接口：渠道、媒体列表、媒体变化、提交订单、查询订单、回调解析、能力清单。
- 统一数据结构：内部渠道、外部媒体ID、媒体名称/状态、成本价、媒体属性、幂等键、外部订单号、统一状态、原始状态、发布链接、失败代码/脱敏原因、回调事件ID、取消/退款标记、部分成功/失败。
- 错误分类：配置缺失、鉴权失败、超时、限流、5xx、响应结构错误、重复外部单号、未知供应商状态、不支持能力、部分失败、重复回调事件。
- MockAdapter：正常渠道/媒体、提交成功、查询成功、退稿、超时、重复外部单号、未知状态、部分失败、退款支持/不支持、回调成功/失败/重复，全部确定性场景。
- 生产禁用 Mock：production 选择 Mock 立即失败；缺失真实适配器失败关闭；不自动降级。
- 数据库：`suppliers`、`channels`，code 唯一，状态和时间字段规范，基础渠道初始化幂等，迁移/回滚/重新迁移。
- 契约测试、Mock 异常场景测试、源码守卫、敏感信息扫描、T01—T08 完整回归。
