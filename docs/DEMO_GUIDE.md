# 5 分钟演示

1. 用 portfolio_demo_a 登录，查看企业资料、虚构企业说明和内容资产。
2. 在问题与答案选择关键词，查看 AI 生成后人工审核的问题。
3. 打开 GEO 优化，选择问题，查看目标答案版本与逐条来源证据。
4. 在内容生产选择 AI 任务，指定问题、提示词、文本知识和已确认目标答案，提交并等待 Worker 完成。
5. 查看文章及历史版本，在媒体目录切换新闻/自媒体/短视频，试用筛选及收藏。
6. 订单财务展示模拟发布成功与退稿两条记录，核对冻结、扣款和解冻流水。
7. 返回 GEO 时间线，查看发布前 Baseline、复检计划、模拟趋势与建议。示例复检使用模拟时间推进，不能作为真实效果证据。
8. 退出并用 portfolio_demo_b 登录，确认其企业内容与 A 隔离。

演示账号密码见 README。没有真实订单、真实付款、真实客户或真实 AI 收录。
