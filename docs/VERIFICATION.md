## 发现并处理

- 最终复查发现原命令会话中的隔离MySQL不再监听（原因未确认），只重启了本演示已有数据目录；重启后10套79条断言及756文件模式扫描再次通过。P:归属通过Windows Unicode QueryDosDevice核验，避免subst输出的中文编码损坏。
- 最后重连保留浏览器页受到工具URL策略阻止，未绕过；此前8张截图和桌面交互已经完成，恢复后的可用性由真实本地HTTP队列测试确认。
- Windows CRLF 模板使带引号的 Base64 密钥跨行：原始 INI 解析模式下先复现失败，再规范换行并验证通过。
- 旧构建脚本可能在内部 Error 后返回0；复现构建同时检查输出 Error/ENOENT。首次复现误排除的 minified 库输入已补回后通过。
- PowerShell5 对无BOM UTF-8心跳和 JSON 数组的处理、Start-Process 退出码读取均经实际启动/停止验证修正。
- 服务停机期间浏览器出现过一条本地网络请求失败日志；重启后目标页面与业务交互成功，未将停机期错误描述成页面零错误。
